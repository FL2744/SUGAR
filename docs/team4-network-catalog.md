# Team 4 network catalog

SUGAR includes a bundled, project-importable catalog compiled from the supplied Team 4 workbooks. Open **Networks and reference directories → Built-in team catalog** to add datasets to a project. The three main layers are selected by default; location leads and selected closure examples are optional.

## Included data

- **Confucius Institutes:** 586 deduplicated master/regional names (583 master-sheet rows plus 3 regional-only names). The workbook notes claim 589, so that disagreement is retained in the catalog.
- **CI location coordinates:** 158 coordinates were attached using a unique same-country name match. The remaining 41 of 199 rows are kept as separate, unmerged location leads because they are unmatched or ambiguous. Every supplied coordinate is labeled unverified. A Baruch College lead’s source coordinates conflict with its stated U.S. host, so they are preserved as a claim but excluded from map coordinates; Baruch’s official page places its campus at 55 Lexington Avenue in Manhattan ([campus map and directions](https://www.baruch.cuny.edu/campus-map-and-directions/)). This check does not confirm a CI affiliation.
- **Luban Workshops:** all 38 detailed location rows, including their source status labels, hosts, partners, specialties, social accounts, and reported posting frequency. The separate 40-name “Active Luban Workshops” list is preserved as its own unlocated dataset rather than auto-merged with the detailed records.
- **American Spaces:** all 559 directory rows, including source status, host, address, locator, and public contact fields.
- **Supplementary leads:** 41 unmatched CI location rows, 40 Luban active-list entries, and 27 selected CI closure examples. The closure examples are not a comprehensive list.
- **Team analysis:** the 94 niche-search rows, 38 Luban specialty queries, all regional-sheet mentions, program-overlap interpretations, and overlap assertions from the source workbooks.

## Status and activity

Catalog status now follows the original workbook label as a working assumption: Active/Open/In Operation/In Reduced Operation/Virtual Programming Only map to **active**; Closed/Temporarily Closed map to **closed**; TBD or missing labels map to **unknown**. The raw wording is retained in the evidence and appears in map details. This makes the map use the team's chosen baseline without presenting it as independent verification. Human-verified registry status takes precedence. A dated post or a directory label alone does not confirm current operation. The supplied Luban detail sheet has a social-media frequency value for only 3 of 38 records and no last-post dates; the American Spaces directory has no per-space post dates.

The public pulse check combines network-level pages with a small, explicitly nonrepresentative set of named-site checks. As of the 2026-10-29 review, the official Confucius Institute portal showed 2026 news through 2026-09-29; that does not establish the cadence or current status of individual institutes ([portal](https://www.ci.cn/en/)). A SCIO/Xinhua report described a 2026-04-20 International Chinese Language Day event at Algiers 2 University; Moi University also posted 2026 Chinese Bridge material naming its Confucius Institute as a co-organizer. The dedicated Moi CI news index still shows a 2023-01-31 item as its newest visible report, so host-campus activity and the institute feed do not give the same cadence signal ([Algiers 2 report](https://english.scio.gov.cn/m/internationalexchanges/2026-04/21/content_118449092.html), [Moi University CI posts](https://mu.ac.ke/index.php/tag/cimu/), [2026 Chinese Bridge material](https://mu.ac.ke/wp-content/uploads/2026/03/confucius_institute_2026_competition.pdf), [Moi CI news index](https://cimu.mu.ac.ke/index.php/media-center/news-report)).

For Luban Workshops, an embassy-hosted Xinhua report dated 2026-10-23 cites China's Ministry of Education for a network total of 38 workshops in 32 countries and describes programs involving students in Egypt and Tajikistan. The count happens to match the supplied detailed sheet, but the report does not reconcile the 38 names one by one. The Mission of China to the African Union separately reported an Ethiopia workshop seminar held on 2025-08-17 ([2026 network report](https://la.china-embassy.gov.cn/eng/news/202610/t20261023_12045908.htm), [Ethiopia event](https://au.china-mission.gov.cn/eng/sghd_1/202508/t20250819_11692597.htm)). For American Spaces, the U.S. Department of State currently describes a network of over 700 locations in 140 countries; the supplied 559-row workbook is therefore not a complete current census ([Office of American Spaces](https://admin.eca.state.gov/programs-and-initiatives/initiatives/office-american-spaces)). Wazi Kenya reports a December 2025 seminar at American Corner Moi University. An instructor’s LinkedIn post claims weekly AI sessions at the American Cultural Center Algiers, but completed sessions were not independently counted ([Wazi Kenya](https://wazikenya.org/programs/health/), [instructor post](https://www.linkedin.com/posts/mehdibourahla_artificialintelligence-ai-acca-activity-7299382801932472320-oBCK)). The [American Spaces locator](https://americanspaces.info/locator/) provides location data, not per-location post history. These examples are saved in `site_activity_spot_checks`; none changes the workbook-based map assumption or proves a regular posting cadence.

Across all 1,183 core rows and 108 supplementary leads, the supplied files contain no explicit per-record last-post date. Separately, we ran a web search for each of the **1,291 catalog rows** on 2026-10-29, with targeted alternate-name searches where the first search did not find a dated or attributable page. The review found 1,235 potentially relevant pages, 239 exact publication-date candidates from page metadata or date-coded URLs, 952 relative search-age labels, and 740 dates shown in search-result text. These categories overlap. There were 56 rows with no relevant page found. Search-result dates can describe an event rather than publication, and a host or third-party page does not establish an institution's own latest post. A matching indexed page also does not establish current activity.

The row-level audit is searchable and paginated in the catalog panel, which can export all results to CSV. Each row preserves the checked date, exact search query, any alternate-name query, date signals, source scope, match strength, and source URLs. The source-scope counts are 511 official/host, 688 third-party or unclear, 36 social/platform, and 56 with no selected source. “Official/host” includes host-institution reporting and is not a claim that the page is the location's own feed. The full result data is included in the built-in catalog and its project reference copy; new registry imports also attach each row's search record to that institution's source evidence. Map status follows the workbook-based assumption unless a person has verified a registry status; the web publication search does not alter status. The five named-site checks above are a separate, selective sample and do not replace this row-by-row search.

## Overlap and maps

The source workbooks contain 144 CI–American Space assertions and multiple Luban–American Space assertion lists. They are stored as team-reported leads, not verified partnerships. The two detailed Luban–American Space workbooks include asserted zero-kilometer/same-host cases even where their supplied coordinates differ. The catalog panel also exposes the team’s eight program and messaging overlap hypotheses with their niche-term IDs and source rows; the UI labels them as hypotheses.

After importing the core datasets, the Map page offers **Confucius Institutes + American Spaces**, **Luban Workshops + American Spaces**, and **All three layers** presets. Active markers retain separate network colors; closed or temporarily closed markers are gray with **×**, and unknown markers are gray with **?**. The map also lists workbook status claims and counts for currently visible layers. Human-verified registry statuses take precedence over workbook assumptions. **Export network map (HTML)** writes an interactive, layer-toggleable HTML file using the selected project records and applies the same status convention. Its dashed proximity lines are on by default and are recalculated from the supplied coordinates at the selected 5, 25, 100, or 250 km threshold; turn that layer off from the map controls if it obscures markers. These lines show geographic proximity only; they do not establish institutional partnership, influence, or causation.

Six focused search queries are available as manually selected suggestions in the research plan’s **Planned searches** section. They are not added automatically; adding one enables only that query and raises the query limit if needed. Broader generic terms from the team discard list are not surfaced.

## Provenance

The complete catalog JSON is copied into references/team4_network_catalog.json when a project imports any of its datasets. Each imported row retains the source workbook and row context in its description/evidence trail. Dataset selections are idempotent: re-importing the same catalog rows skips entity IDs already in the project.

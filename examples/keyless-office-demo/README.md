# Credential-free office demo

Run `python examples/keyless-office-demo/build_demo.py` from the repository root.
It prints a standalone HTML country snapshot and an analysis ZIP in a new temporary
workspace. Open the HTML in any browser; it requires no install, credentials, tiles,
or network access. Evidence links open only when the reader chooses them.

All institutions, programs, attendance figures and reference locations in this demo
are explicitly **synthetic**. Mexico provides the geographic frame, not research
findings. Example URLs are placeholders. Use actual sourced project records for a
sponsor-facing analytical brief.

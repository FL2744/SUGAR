# SUGAR examples

This directory contains example outputs retained to demonstrate SUGAR file formats and provide convenient human-readable references during development.

Current examples include:

- `example-spreadsheet.xlsx` — sample tabular research output;
- `example-map.html` — sample interactive map;
- `example-analysis.docx` — sample Word analysis product;
- `example-analysis.pdf` — sample PDF analysis product.

These files are **examples, not authoritative Diplomacy Lab research data**. They should not be cited as current findings, used as a substitute for source provenance, or treated as proof that a current collector/workflow produces byte-identical output.

When behavior or schemas change, deterministic automated tests remain the source of truth for compatibility. Update or regenerate example files only when doing so materially improves documentation; avoid committing routine/generated research outputs to the repository.

Do not place credentials, private notes, sensitive source material, or user-specific data in this directory.

# SUGAR examples

This directory contains format examples and one curated, source-backed research workspace for sponsor demonstrations.

Current examples include:

- `example-spreadsheet.xlsx` — sample tabular research output;
- `example-map.html` — sample interactive map;
- `example-analysis.docx` — sample Word analysis product;
- `example-analysis.pdf` — sample PDF analysis product.
- [`ghana-education-research/`](ghana-education-research/README.md) — a small EducationUSA, American Spaces, and University of Ghana demo with source-backed registry claims, an interactive map, and a portable handoff bundle.

These files are **examples, not authoritative Diplomacy Lab research data**. They should not be cited as current findings, used as a substitute for source provenance, or treated as proof that a current collector/workflow produces byte-identical output. The Ghana demo documents its source scope, map precision, and evidence gaps alongside its generated project.

When behavior or schemas change, deterministic automated tests remain the source of truth for compatibility. Avoid committing routine or user-specific research outputs to the repository.

Do not place credentials, private notes, sensitive source material, or user-specific data in this directory.

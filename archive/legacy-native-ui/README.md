# Archived native SUGAR clients

This directory preserves the pre-1.4 Windows PySide6 and macOS SwiftUI clients, their packaging scripts, and their UI-focused tests for historical reference.

The supported interface is now the shared React and TypeScript frontend in `SUGAR-Desktop`. Browser use connects to the Python SUGAR API; optional Tauri packages run the same frontend and the existing Python research core. The archived clients are not runtime fallbacks, build inputs, or supported launch paths.
